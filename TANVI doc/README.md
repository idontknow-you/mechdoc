# Shared MechDoctor frontend components

All six JSX components in this folder are imported directly by the application in `../mechdoctor-main/frontend`.

Open **http://localhost:5000** while the backend is running. The backend serves the built frontend and all API endpoints together.

To restart, double-click `../mechdoctor-main/Start-MechDoctor.cmd`.

The HTML entry in this folder also uses the same connected application. Run `npm.cmd run dev` here with the backend running for development. The main project and tests are documented in `../mechdoctor-main/README.md`.
